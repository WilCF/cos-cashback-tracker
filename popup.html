Email setup (one-time, ~2 min)
  1. Open script.google.com → New project.
  2. Paste the code from email_relay.gs (included with the extension).
  3. Deploy → New deployment → Web app; “Execute as: Me”, “Who has access: Anyone”.
  4. Authorize, copy the /exec URL, paste it below.

Email is off until you add a URL. When enabled, the extension sends only your matched deals and the email address you enter to the Apps Script URL you provide, so it can email you — nothing is sent anywhere else, and there is no analytics or tracking.
